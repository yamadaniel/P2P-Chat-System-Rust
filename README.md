# P2P通信を使用したチャットアプリ

## 使用言語
- Rust(Tauri)
- HTML
- CSS
- JavaScript

## 使用技術
- Rust
- SQLite
- iroh

## 概要
チャットの際に中央サーバーを経由せずにP2P(Peer-to-Peer)で通信を行うシステム

中央サーバーは以下の際に利用される
- 新規登録
- ログイン
- ユーザー検索
- オンライン表示

それら以外で中央サーバーは使わない

## 目的
- P2P通信を利用した中央サーバーに依存しないサービスの作成
- メッセージ本文がサーバーを通らず、どこにも保存されない
- 最悪の場合、中央サーバーがダウンしてもチャットを行うことはできる

## 現状の疑問・課題
- ポート開放なしでインターネット間での通信ができるか
 - -> irohでは可能らしいが、不可の場合はirohのリレーを使用（要検証）
- 本当に中央サーバー無しでも通信が可能なのか
- OracleAlwaysFree以外にサーバーはないのか

## 現状の想定
PC-Aで登録 -> 中央サーバーに情報を送信

PC-BからユーザーIDを検索 -> 中央サーバーでの処理

PC-AとPC-Bでチャット -> P2P通信でサーバーを介さない

オンライン状態の確認は2段階
- ① 定期的にping的なものをPC側から送信
- ② ①でオンライン判定された相手に対しこちらからping
- ③ ②の結果でオンラインの真偽を判定
